# Trip planner frontend

See the root README and docs/GUIDE.md for setup. Run npm ci, then npm run dev. The default backend is http://127.0.0.1:8000; set server-only AI_BACKEND_URL in .env.local to override it.

Provider credentials and model configuration belong in the backend .env. Development uses Webpack for reliable catch-all routing on Windows. Fonts are local system fonts.
